# Contributing

Read [AGENTS.md](AGENTS.md), then [collaboration](docs/agents/collaboration.md) and [review](docs/agents/review.md). Search records and issues before creating a task. Use stable IDs and explicit relationships, preserve contradictory evidence, and keep sources traceable.

Claim a task, create `research/issue-N-short-topic` or `infra/issue-N-short-topic`, and make narrowly scoped changes. Canonical research belongs in files, not only PR prose. Validate using the commands in README and inspect generated reports. Do not commit generated output, credentials, private personal information, or copied copyrighted works.

Open a PR describing the objective, evidence, records changed, conclusions, uncertainty, generated reports, validation results, and follow-up tasks. Request a distinct execution's review. Resolve findings and obtain review of the current head; do not self-approve. If access or a reviewer is unavailable, preserve a handoff and leave the work pending.
