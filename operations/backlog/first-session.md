# First research session: bounded discovery

Status: ready only after bootstrap review and configuration. This brief has not been researched.

Objective: identify three distinct US small-business administrative customer problems across at least two industries using permitted public primary or near-primary sources. Start with problems and existing workarounds, not AI product concepts. Time-box initial exploration to one invoked session; deepen only one signal if evidence warrants it.

Before starting, inspect Issues, PRs, records, and handoffs; create or find a matching discovery issue and claim it. Acceptance: cite actual source records with access dates and limitations; document affected customers, friction, counterevidence, and explicit unknowns; deduplicate; recommend one highest-value next question. Fewer than three credible signals is acceptable with an honest explanation; never fabricate to meet a quota.

Validate records, generate reports, open a PR, request independent review, and preserve a handoff if unfinished. Do not contact customers or run experiments. Bootstrap must not execute this task.
